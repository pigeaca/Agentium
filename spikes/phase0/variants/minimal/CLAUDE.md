# Agentium

Development tooling for a planned AI development lab. There is no product code yet.

- The harness is `.agents/scripts/harness.py` (Python standard library only); its tests are in `.agents/scripts/test_harness.py`.
- Run the tests with `python3 -m unittest discover -s .agents/scripts -p test_harness.py`.
- Keep changes small and in the surrounding style. Update the tests and the docs that describe any behavior you change.
