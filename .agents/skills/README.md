# Local skills

- `product-increment`: plan, implement, verify, review and publish a cohesive increment as a PR.
- `use-agentium`: for agents that *use* the tool for its owner (free commands, preview first, paid runs only after a yes, the report in plain words), not for building it. The owner copies it into their own skills folder.

Skills follow the core rules and use the harness. Routine task-scoped Git operations follow the standing [Git authorization](../rules/git-workflow.md); other external effects still require explicit scope.

Canonical bodies live here. Claude discovery uses thin adapters in `.claude/skills/`; keep their names/descriptions and links in sync (`check docs` enforces it). Add a skill only for a procedure that repeats. See [agent setup](../reference/agent-setup.md).
